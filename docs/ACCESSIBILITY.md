# Accessibility

**Status:** Proposed.

- Every control has an accessible name and meaningful automation properties.
- All workflows are keyboard reachable with visible focus.
- Do not communicate locked/unlocked state by color alone; use text and icons.
- Error messages identify the problem and the safe next action.
- Password fields must not expose entered text or it through logs.
- Respect Windows high-contrast and reduced-motion preferences where WPF supports them.
- Verify at practical Windows text scaling levels before release.
