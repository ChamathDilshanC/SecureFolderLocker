# Roadmap

**Status:** Proposed.

## Phase 1 - Foundation

Create the .NET 8 WPF solution, MVVM shell, dependency boundaries, SQLite migration runner, and baseline tests.

## Phase 2 - Secure MVP

Implement first-run password setup, BCrypt verification, folder selection/validation, ACL adapter, reconciliation, and actionable error handling.

## Phase 3 - Usable Windows product

Apply WPF-UI styling, accessibility behavior, settings/about content, logging with redaction, and installer packaging.

## Phase 4 - Release hardening

Complete clean-machine testing, recovery tests, dependency review, documentation, signing decision, and release checklist.

Dependencies: ACL behavior and recovery must be validated before installer release. Numeric delivery dates and performance targets are TBD.
